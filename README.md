# AI with Prof. Prakash

Website of Dr. Prakash S: https://aiwithprofprakash.com

Plain HTML, hosted on GitHub Pages. No build step.

## How to add a page
1. Copy `pages/_template.html` to `pages/<name>.html` (or use "Pages" in Pages CMS).
2. Put any HTML between `<main>` tags.
3. Add it to `menu.json` as `{"title": "My page", "url": "pages/<name>.html"}`.

Changes go live in about a minute after saving.
